# Reference-голоса для Local GPU (XTTS)

Положите сюда свои `.wav`-файлы (рекомендуется mono, 24 кГц, 15-30 секунд,
без шумов и клиппинга) — они автоматически появятся в выпадающем списке голосов
у провайдера **Local GPU** в веб-студии (после перезапуска сервера или обновления
страницы).

- Файлы `*.wav` в этой папке не коммитятся (gitignore).
- Дополнительные папки можно добавить через `RF_XTTS_VOICES_DIR` (несколько через `;`).
- Голос по умолчанию (если не выбран в UI) — из `RF_XTTS_SPEAKER_WAV`.
