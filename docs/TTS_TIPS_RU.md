# Советы по озвучке: английские термины в русских репликах

Проверено на локальном XTTS (external worker, голос из YouTube-референса):
в **русской** фразе встроенные английские слова (коды, позывные, названия
ракет) звучат «наполовину» — модель озвучивает всё высказывание под один
языковой токен и не переключается на английский внутри реплики.

**Правило:** военные термины и позывные в русских репликах пишите
**кириллицей** (транслитом), а не латиницей.

## Примеры замен

| Латиница | Кириллица (рекомендуется) |
|---|---|
| AGM-65 Maverick | Эй Джи Эм шестьдесят пять Мэверик |
| AGM-65B Maverick | Эй Джи Эм шестьдесят пять бэ Мэверик |
| F-4E | Эф четыре и |
| WSO | оператор вооружения |
| A/G | воздух-земля |
| AWACS | АВАКС |
| JTAC | Джитак |
| FAC | ФАК |
| GCI | Джи-Си-Ай |
| bulls | буллз |
| bogey | богги |
| push | пуш |

Пример из проверенного урока (AGM-65 Maverick):

> «Этот урок посвящён применению ракеты Эй Джи Эм шестьдесят пять Мэверик…
> применяемая на истребителе Эф четыре и… оператор вооружения также может
> захватывать цель и выполнять пуск ракеты.»

## Когда это не нужно

- Если **вся** фраза английская — озвучивайте её целиком с `language: "en"`
  (не смешивайте языки в одной реплике).
- Edge TTS и ElevenLabs с этим правилом тоже работают лучше: меньше шансов,
  что движок прочитает латинское слово «как написано».

## Как проверить

Кнопка «Проверить голос» в редакторе (провайдер Local GPU) или
`POST /api/tts/preview` с `provider: "external"` — сравнивайте латинский и
транслитерированный варианты перед генерацией миссии.
