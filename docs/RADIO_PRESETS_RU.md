# Гайд по радио-пресетам

SRS-like пакет сделан через ffmpeg-фильтры: ограничение полосы, EQ, компрессия, шум, щелчки рации и короткий хвост передачи.

## Пресеты

| Пресет | Звук | Где использовать |
| --- | --- | --- |
| Clean studio | Чистый, нормализованный | Исходник для внешней обработки |
| SRS VHF AM | Узкий, яркий, занятой эфир | JTAC, FAC, низкий эшелон |
| SRS UHF AM | Чище, сильнее сжат | Истребительная связь |
| SRS FM | Плотнее и шире | Наземка, вертолёты, конвой, CSAR |
| SRS cockpit mic | Близкий шлемофон | Ведомые, звено, cockpit chatter |
| SRS AWACS | Чёткий командный голос | AWACS, GCI, picture calls |
| SRS bad reception | Шумный, забитый, дальний | Слабый сигнал, горы, terrain masking |
| Old Soviet radio | Грубый и узкий | Русский GCI, старая наземная рация |

## Качество сигнала

- `85-100`: читаемая профессиональная радиосвязь.
- `65-84`: слегка грязная тактическая связь.
- `40-64`: заметно слабый приём.
- `15-39`: аварийная или сильно закрытая передача.

## Щелчки рации

Включай щелчки для ощущения push-to-talk. Выключай, если хочешь добавлять свои клики во внешнем редакторе.

## Совет для DCS

В самой миссии звук часто тонет в двигателе, пусках, взрывах и музыке. Поэтому радио может казаться чуть громче и чище в одиночном прослушивании - это нормально.
